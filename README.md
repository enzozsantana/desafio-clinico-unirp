# Desafio Clínico UNIRP — Avaliador

Avaliador web para professores do Desafio Clínico (Enfermagem / UNIRP).

## Uso

Abra o site publicado e entre com a conta de professor.

## Stack

- HTML + Supabase (Auth, Postgres, Storage)

## Desenvolvimento

Edite `avaliador-desafio-clinico.html` e copie para `index.html` antes de publicar, ou edite os dois se estiver trabalhando só no deploy.
